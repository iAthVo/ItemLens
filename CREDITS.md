## Your own data

Everything ItemLens **learns while you play** (vendors, loot, quests, recipes) is gathered by
ItemLens itself from your game client and stored only on your PC (`ItemLensDB.learned`).

## Optional compatibility

| Addon | Authors | What ItemLens does with it |
|---|---|---|
| **Syndicator** | plusmouse | If installed, adds characters and banks that ItemLens hasn't seen yet. ItemLens works fully without it. |
| **TomTom** | Cladhaire, Ludovicus | If installed, 📍 uses its waypoint arrow. Without it, the native map pin is used. |

ItemLens contains no code from these addons; it only uses their public APIs when present.
